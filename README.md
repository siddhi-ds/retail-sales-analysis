Retail Sales Analysis Using Python

Project Overview
This project analyzes retail sales data using Python. The main aim is to understand sales performance, product categories, regional sales, and profit.

Tools and Technologies
Python
Pandas
Matplotlib
VS Code

Dataset

Total Sales by Category
Total Sales by Region

Key Findings
Technology has the highest sales among the three product categories.
The West region has the highest total profit.
No missing values or duplicate records remained after cleaning.
